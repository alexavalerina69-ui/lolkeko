# РАЗЛОМ · RIFT PROTOCOL

> Кооперативный хоррор-экстракшн в духе **Tarkov × GTFO × VOTV**.
> Играбельная 3D-вертикаль на Three.js — работает прямо в браузере, хостится на GitHub Pages.

**Версия:** 0.1.0 (vertical slice)

---

## 🎮 О чём игра

Ты — оперативник «Ковчега». Зона отчуждения «Объект-9» — место, где пространство
существует в нескольких версиях сразу. Твоя задача: спуститься в комплекс, собрать
**3 образца** и эвакуироваться через шлюз.

Проблема — **«Слепой»**: гуманоидный хищник без зрения. Он не видит свет.
**Он слышит.** Шаги, спринт, крик — всё работает как сирена. Эхолокация
прощупывает Зону регулярными импульсами. Единственный протокол выживания — **тишина**.

Между заходами — база «Ковчег»: модернизация снаряжения, досье объектов, радиожурнал.

---

## ▶️ Как играть

Любой статический сервер (или GitHub Pages после влития в `main`):

```bash
# локально
npm run serve          # python3 -m http.server 8080
# → http://localhost:8080
```

Открой страницу, нажми **«ВОЙТИ В ЗОНУ»**. Мышь захватывается автоматически —
кликни по экрану, если потерялся фокус.

> Всё работает без сборки и без внешних ассетов: графика — процедурная,
> звук — синтезируется в WebAudio. Three.js лежит в `lib/`.

## 🧠 Механики вертикали

- **Слух монстра** — сущность реагирует на шумовые события: спринт слышен на ~17 м,
  шаг — на ~10 м, приседание — на ~5 м. Эхолокация «прощупывает» громких.
- **Стамина / АКБ / Психика** — ресурсы решают, как долго ты можешь бежать,
  светить и оставаться в адеквате. Темнота и близость монстра разрушают психику.
- **Галлюцинации** — при низкой психике появляются силуэты, шёпоты, искажения.
- **Лут и артефакты** — образцы, АКБ, аптечки, светошумовые, редкие артефакты.
- **Эвакуация** — шлюз активируется только после сбора всех образцов. Возврат к
  точке входа — последний и самый страшный отрезок.
- **Всплеск** — после 7-и минут в Зоне монстр ускоряется, атмосфера сгущается.
- **Мета-прогресс** — кредиты, уровни, 5 веток улучшений, досье «Слепого»,
  радиожурнал с лором. Смерть отнимает снаряжение, но не знания.
- **Сложность** — «Стандарт» и «Глубина» (+60% наград, быстрее и злее монстр).

## 🗂️ Структура проекта

```
index.html            — разметка всех экранов
css/style.css         — интерфейс (тёмная индустриальная эстетика)
lib/                  — vendored three.js r170 + аддоны
src/
  main.js             — точка входа, игровой цикл, состояние
  core/
    audio.js          — процедурный звук (WebAudio, без ассетов)
    input.js          — клавиатура/мышь/pointer lock
    save.js           — localStorage
  game/
    world.js          — процедурная генерация комплекса (BFS, коллизии)
    player.js         — FPS-контроллер, статы, фонарь
    monster.js        — ИИ «Слепого»: патруль/расследование/погоня
    loot.js           — предметы и артефакты
    effects.js        — галлюцинации, вспышки, искажения
    textures.js       — процедурные canvas-текстуры
    hud.js            — HUD рейда
  ui/
    ui.js             — меню, база «Ковчег», улучшения, досье, радио
test/
  world-test.mjs      — стабильность генерации (25 итераций)
  sim-test.mjs        — симуляция физики и ИИ без WebGL
.github/workflows/    — деплой на GitHub Pages
```

## 🧪 Разработка

```bash
npm install            # dev-зависимости (three, esbuild)
npm test               # смоук-тесты мира и симуляции
npm run check          # esbuild-бандл чек
npm run serve          # локальный сервер
```

## 📡 GitHub Pages

В репозитории есть workflow `.github/workflows/pages.yml`:
при пуше в `main` автоматически деплоит статику на GitHub Pages
(**Settings → Pages → Source: GitHub Actions**).
